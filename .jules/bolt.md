## 2024-04-14 - Replace fuse.js with fuzzysort for fuzzy string matching
**Learning:** `fuzzysort` requires `fuzzysort.prepare()` to be used explicitly when performing multi-field search (via `keys`). In contrast to `fuse.js`, if you specify `keys` in `fuzzysort.go`, the target fields must be pre-prepared or mapped correctly. `fuzzysort` also scores negatively, so its score must be normalized to `0-1` to maintain compatibility with logic that expects `fuse.js`-like positive scores (using `Math.min(1, Math.max(0, (score + 1000) / 1000))`).
**Action:** When migrating from `fuse.js` to `fuzzysort`, always ensure target fields in arrays of objects are mapped with `fuzzysort.prepare()`, and implement a score normalization function to avoid breaking downstream threshold logic.
