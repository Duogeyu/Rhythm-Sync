## 2024-04-20 - DP Matrix Optimization via Pre-allocated Uint16Array
**Learning:** In the Node.js backend, since synchronous code within route handlers runs single-threaded without preemption, memory-intensive inner loops (like DP matrices for string similarity) can be optimized by replacing `O(N*M)` 2D array allocations with an `O(min(N,M))` sliding window approach. Furthermore, by using a single, globally reusable `Uint16Array` (with a dynamic allocation fallback for edge-case large strings), we drastically reduce garbage collection pressure.
**Action:** When optimizing memory-intensive DP algorithms on the backend, define a shared, global fixed-size buffer (e.g., `Uint16Array`) and apply space-optimized DP. Always include a dynamic allocation fallback for inputs that exceed the buffer's maximum length.
