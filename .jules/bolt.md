## 2024-04-15 - Synchronous JSON Parsing Bottleneck in Express Backend
**Learning:** The Express backend was previously reading and `JSON.parse`ing song lists via `fs.readFileSync` on *every* single cache hit if the file was within `CACHE_DURATION`. For a 5000+ item array, this synchronous I/O and parsing blocked the Node.js event loop for nearly 4ms per request. Under heavy load, this is a catastrophic architectural bottleneck because Express processes requests on a single thread.
**Action:** When working with file-based cache in Node.js server environments, always layer an in-memory `Map` (or LRU cache) on top of the synchronous file reads for hot data. I reduced read latency from ~3.9ms to ~0.01ms (a 300x improvement) by caching the parsed objects in memory. Always remember to invalidate *both* memory and file stores when clearing the cache.
