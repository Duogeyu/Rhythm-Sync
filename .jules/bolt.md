## 2024-04-12 - Replacing Fuse.js with fuzzysort for fuzzy matching
**Learning:** `Fuse.js` instances are slow to initialize over large arrays and incur a substantial performance hit on nested iterations such as fuzzy matching requests inside a loop. Since `fuzzysort` is native and heavily optimized, it performs much faster but requires inputs to be explicitly pre-processed using `fuzzysort.prepare()` to avoid skipping matching fields and mapping scores.
**Action:** Always favor `fuzzysort.go` with `.prepare()` over `new Fuse()` for any array searching or fuzzy matching on the server to prevent bottlenecks, specifically ensuring to normalize native negative scores (`Math.max(0, (score + 1000) / 1000)`) and translating `fuse.js` threshold thresholds (e.g. `0.3` -> `-300`).
