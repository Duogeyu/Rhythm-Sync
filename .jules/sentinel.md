## 2026-04-20 - Global Path Traversal Protection
**Vulnerability:** Multiple API endpoints (`/api/covers/:gameId/:fileName`, `/api/bot/result/:id`, `/api/random/image/:id`, etc.) use user input directly in `path.join` without path traversal validation.
**Learning:** `req.params` parameters must be validated to prevent directory traversal (`..`, `/`, `\`) before being used in file system operations.
**Prevention:** Implement a global `isSafeFilename` middleware using `app.param()` to automatically reject any unsafe paths across all endpoints.
## 2026-04-20 - Global SSRF Protection via HTTP Agents
**Vulnerability:** The application fetches external images via `axios.get(req.query.url)` without validating the destination, allowing attackers to access internal network services (SSRF) and bypass protections via DNS Rebinding. Additionally, on failure, it performed an unsafe redirect (`res.redirect(originalUrl)`), creating an Open Redirect.
**Learning:** Checking URLs with regex or string manipulation before a request is insufficient due to TOCTOU (Time-of-Check to Time-of-Use) issues with DNS resolution. Custom `http.Agent` and `https.Agent` implementations that hook into `dns.lookup` are required to securely validate the exact IP address before the socket connects.
**Prevention:** Implement a global `isInternalIp` function that validates against RFC1918, loopback, and metadata ranges (including IPv6 equivalents). Pass a custom `lookup` function to global `safeHttpAgent`/`safeHttpsAgent` singletons to ensure every outbound request from `axios` validates the resolved IP. Remove any unsafe fallback redirects in proxy endpoints.
