## 2026-04-20 - Global Path Traversal Protection
**Vulnerability:** Multiple API endpoints (`/api/covers/:gameId/:fileName`, `/api/bot/result/:id`, `/api/random/image/:id`, etc.) use user input directly in `path.join` without path traversal validation.
**Learning:** `req.params` parameters must be validated to prevent directory traversal (`..`, `/`, `\`) before being used in file system operations.
**Prevention:** Implement a global `isSafeFilename` middleware using `app.param()` to automatically reject any unsafe paths across all endpoints.
## 2025-02-24 - SSRF vulnerability in Proxy Endpoint
**Vulnerability:** The `/api/covers/:gameId/:fileName` endpoint fetched images using user-provided URLs in `req.query.url` directly via `axios.get` without validating the host, enabling attackers to scan internal networks, access loopback addresses (like `127.0.0.1`), or access cloud metadata services.
**Learning:** Even innocuous-looking proxy endpoints intended for downloading images are critical SSRF vectors. Attackers can use 302 redirects or DNS rebinding (TOCTOU) to bypass simple regex or initial DNS checks. Furthermore, internal IP blocks must comprehensively cover IPv4, IPv6, IPv4-mapped IPv6, `0.0.0.0`, and `169.254.x.x` (cloud metadata).
**Prevention:** Implement a robust `isValidExternalUrl` utility that: 1. validates protocols (http/https); 2. performs a preemptive DNS lookup (`dns.promises.lookup`); 3. normalizes IPv4-mapped IPv6 addresses (`::ffff:`); 4. comprehensively blocks internal/reserved IP ranges (`127.x`, `10.x`, `192.168.x`, `172.16-31.x`, `169.254.x`, `0.0.0.0`, `::1`, `fc00:`, `fd00:`, `fe80:`). To prevent TOCTOU, the request *must* be rewritten to use the resolved IP address, while preserving the original port, `Host` header, and SNI (`httpsAgent: new https.Agent({ servername })`). Finally, explicitly set `maxRedirects: 0` to prevent redirect bypasses.
