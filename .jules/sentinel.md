## 2024-05-18 - Path Traversal in File-Serving APIs
**Vulnerability:** Path Traversal vulnerability found in multiple Express routes (e.g., `/api/covers/:gameId/:fileName`, `/api/bot/result/:id`, `/api/share/:id/image`) serving files directly from user-controlled dynamic route parameters (`req.params`) using `path.join()` without sufficient validation.
**Learning:** `path.join()` normalizes the path but doesn't inherently prevent escaping the base directory if the input contains `../` sequences or absolute paths (on some OS configurations). The reliance on naive `fs.existsSync` combined with unvalidated path segments allowed reading arbitrary files within the filesystem scope accessible to the Node process.
**Prevention:** Always strictly validate and sanitize dynamic route parameters that represent filenames or IDs used in file I/O operations. Implement functions like `isSafeFilename` utilizing regex strictly allowing alphanumeric characters, underscores, dots, and hyphens (e.g., `/^[a-zA-Z0-9_.-]+$/`), and explicitly rejecting `../`, `/`, and `\`.
