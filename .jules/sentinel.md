## 2026-03-11 - Path Traversal Vulnerability in Express Endpoints
**Vulnerability:** Multiple `app.get` endpoints in `server/index.js` (e.g. `/api/random/image/:id`, `/api/bot/result/:id`, `/api/share/:id/image`) directly used dynamic route parameters (like `:id` and `:shareId`) in `path.join()` without prior validation, passing the result to file system operations (`fs.existsSync` and `fs.readFileSync`). This permitted Path Traversal attacks (e.g., passing `../../../etc/passwd` via URL parameters to retrieve server-side files).
**Learning:** Even if `path.join` resolves paths, without input validation it will still allow attackers to break out of the intended directory using `../`. Express `req.params` are URL-decoded by default, making it easy to inject such sequences via `%2f`.
**Prevention:** Implement an `isSafeFilename` function to strictly filter input (`!filename.includes('..') && !filename.includes('/') && !filename.includes('\\') && !filename.includes('\0')`) before passing dynamic parameters into any `path.join` or `fs.*Sync` methods.
