## 2024-05-24 - [Fix Path Traversal in File Operations]
**Vulnerability:** Path traversal vulnerabilities found in multiple endpoints (`/api/covers/:gameId/:fileName`, `/api/admin/clear-cache`). Express route parameters and request body fields (e.g., `gameId`, `fileName`) were passed directly into `path.join()` or `fs.existsSync()` without validation, allowing attackers to access or delete arbitrary files on the system using `../` sequences.
**Learning:** In Node.js/Express applications, user-supplied path components must always be sanitized before being used in file system operations. `path.join()` alone does not prevent path traversal if the resulting path is not checked against a base directory.
**Prevention:** Implement an `isSafeFilename` validation function and apply it globally using `app.param()` for path-related route parameters. For other inputs (like request body), validate against a strict whitelist (e.g., the `GAMES` object) before using them in file operations. Ensure the validation does not unnecessarily block valid IDs containing characters like `|` or `:`.
