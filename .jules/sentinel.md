## 2024-05-24 - Express Path Traversal via Dynamic Route Parameters
**Vulnerability:** Path traversal vulnerabilities identified in several file-serving endpoints using Express dynamic route parameters without proper validation, such as `/api/covers/:gameId/:fileName`, where parameters passed to `path.join()` or `fs` methods could contain traversal sequences like `..` leading to unauthorized file access.
**Learning:** Express decodes URL parameters (e.g., `%2f` to `/`). When evaluated by `path.join()`, this allows traversal payloads to bypass route matching and trigger a path traversal vulnerability. Standard regex alphanumeric checks can break existing formats containing characters like spaces, hyphens, and periods.
**Prevention:** Implement an `isSafeFilename` utility to validate filenames and IDs against path traversal attacks. This function must explicitly block directory traversal characters (`..`, `/`, `\`, `\0`) instead of relying on an overly strict regex. Additionally, ensure validation failures immediately return an HTTP 400 Bad Request with a JSON error message before passing the dynamic parameters to `path` or `fs` methods.
