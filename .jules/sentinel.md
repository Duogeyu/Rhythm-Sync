## 2026-04-07 - [Express Global Route Parameter Path Traversal Vulnerability]
**Vulnerability:** Path traversal payload passing through Express dynamic route parameters without validation (e.g., `req.params.id`). When `req.params` values are supplied to `path.join()`, specifically via percent-encoded traversal inputs (e.g., `%2f` instead of `/`), Express decodes it correctly, bypassing generic route-matching blocks but executing a directory traversal operation during `path.join()`.
**Learning:** Using Express, route parameters decoded values bypass conventional slash-matching in the router. An attacker could exploit endpoints using parameterized file access (e.g., `/api/random/image/:id`) by sending URL-encoded payload (e.g., `/api/random/image/..%2f..%2fetc%2fpasswd`), resulting in arbitrary file exposure.
**Prevention:** Implement a global middleware layer on expected parameterized names (`app.param(['id', 'fileName', ...])`) validating against a safe boundary (`isSafeFilename()`) that blocks `..`, `/`, `\`, and `\0`. Fail fast and securely via `res.status(400)` to ensure path inputs are strictly alphanumeric or standard characters before further path computation.
