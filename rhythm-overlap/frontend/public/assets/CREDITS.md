# 美术素材来源说明

本项目使用的游戏相关美术素材均来自各游戏官方网站，仅用于学习和展示目的。

## 目录结构

```
public/
├── logos/           # 游戏 Logo
│   ├── maimai-*.png
│   ├── chunithm-*.png/webp
│   ├── ongeki.webp
│   └── taiko.png
└── assets/
    ├── characters/  # 角色立绘
    └── backgrounds/ # 背景素材
```
